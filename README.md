I build privacy focused browser tools with a simple goal: give people more control over what they see online.

## What This Project Is

`Unquery` is a browser extension that removes AI overview blocks and AI summaries from search pages, while showing estimated water and energy impact.

- Supports major search engines
- Runs locally in the browser
- Keeps dependencies low
- Keeps UI clean and readable

Repository: https://github.com/unquerys/unquery

## Solo, By Design

This is a solo project built with consistency and care.

I started it from a simple idea: search should feel direct, calm, and user controlled. The project is maintained with long term quality in mind, not short term noise.

## Goals

- Build tools that respect user attention
- Keep software lightweight and understandable
- Prioritize privacy first defaults
- Keep design grounded, warm, and practical

## Planned Features

- Expanded privacy protection beyond AI summary blocking
- Optional tracker and nuisance element blocking modes
- More customization for strictness and per-engine behavior
- Better per-site controls from the popup
- Cleaner reporting and visibility into what was blocked

## Design Direction

Earth tone visual language, low noise UI, and a focus on clarity over clutter.
